# Substack Social Cross-Poster

Automatically generates social media cross-posts when you publish on Substack. Fetches your RSS feed, extracts the post content and featured image, generates relevant hashtags using Claude's API, and formats ready-to-post content for Twitter/X, Facebook, and Instagram.

## Quick Start

```bash
cd tools/substack-crosspost

# Install dependencies
pip install -r requirements.txt

# Set up config
cp config.example.json config.json
# Edit config.json — add your Anthropic API key for smart hashtags

# Run a dry-run to see formatted posts
python crosspost.py --once --dry-run
```

## Usage

```bash
# Check feed once, print formatted posts to terminal
python crosspost.py --once --dry-run

# Output as JSON (for Zapier/webhook integration)
python crosspost.py --once --format json --dry-run

# Process ALL posts (ignore already-processed tracking)
python crosspost.py --once --dry-run --all

# Check feed once and post to configured platforms
python crosspost.py --once

# Poll every 15 minutes (configurable in config.json)
python crosspost.py
```

## Configuration

Copy `config.example.json` to `config.json` and edit:

| Field | Description |
|-------|-------------|
| `feed_url` | Your Substack RSS feed URL |
| `poll_interval_minutes` | How often to check for new posts (default: 15) |
| `dry_run` | `true` to print without posting, `false` to post via APIs |
| `anthropic_api_key` | Your Anthropic API key for Claude-powered hashtags |
| `hashtag_count` | Number of hashtags to generate (default: 10) |
| `custom_hashtags` | Branding hashtags always prepended (e.g., `["#Substack"]`) |
| `twitter.*` | Twitter/X API v2 credentials |
| `facebook.*` | Facebook Page Graph API credentials |
| `instagram.*` | Instagram Business Graph API credentials |

All API keys can also be set via environment variables:

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
export TWITTER_API_KEY="..."
export TWITTER_API_SECRET="..."
export TWITTER_ACCESS_TOKEN="..."
export TWITTER_ACCESS_TOKEN_SECRET="..."
export FACEBOOK_PAGE_ID="..."
export FACEBOOK_ACCESS_TOKEN="..."
export INSTAGRAM_ACCOUNT_ID="..."
export INSTAGRAM_ACCESS_TOKEN="..."
```

## Hashtag Generation

With an Anthropic API key configured, hashtags are generated by Claude (using the cost-efficient Haiku model). Claude analyzes your post title and content to produce contextually relevant, trending-style hashtags.

Without an API key, the tool falls back to a keyword-frequency method that extracts the most prominent terms from your post.

## Zapier Integration

The `--format json` flag outputs structured JSON, making it easy to integrate with Zapier:

1. **Zapier Trigger:** "New Item in RSS Feed" for `missgayle.substack.com/feed`
2. **Zapier Action:** Run this script via webhook or Code step
3. **Zapier Actions:** Post to Twitter, Facebook, Instagram using Zapier's built-in integrations

JSON output includes: `title`, `link`, `image_url`, `hashtags`, `twitter_text`, `facebook_text`, `instagram_text`, and `generated_at`.

## How It Works

1. **Fetches** your Substack RSS feed
2. **Detects** new posts (tracks processed posts in `processed.json`)
3. **Extracts** the featured image from the post's HTML content
4. **Generates** hashtags via Claude API (or keyword fallback)
5. **Formats** platform-specific posts:
   - **Twitter/X:** Title + link + hashtags (fits 280 chars)
   - **Facebook:** Title + description excerpt + link + hashtags
   - **Instagram:** Title + description + "Link in bio" + hashtags
6. **Posts** to configured platforms (or prints in dry-run mode)

## Platform API Setup

### Twitter/X
1. Apply for a [Twitter Developer account](https://developer.twitter.com/)
2. Create a project/app with Read and Write permissions
3. Generate API Key, API Secret, Access Token, and Access Token Secret

### Facebook
1. Create a [Facebook App](https://developers.facebook.com/)
2. Add the Pages API product
3. Generate a Page Access Token with `pages_manage_posts` permission

### Instagram
1. Requires a Facebook Business account linked to your Instagram Business/Creator account
2. Use the [Instagram Graph API](https://developers.facebook.com/docs/instagram-api/)
3. Generate a token with `instagram_basic` and `instagram_content_publish` permissions
